# Provenance / Hazırlanma süreci

This collection was developed in an AI-assisted conversation for Onur Kızılarslan’s structural optimization coursework. OpenAI ChatGPT/Codex assisted with code, teaching explanations, numerical checks and visualizations. It is not a transcription of an instructor’s erased classroom example, nor a peer-reviewed research result.

The repository packaging preserves all original lesson files; only Turkish folder-navigation references in OKU.md were adapted. English/Turkish entry pages and a collection validation runner were added. Earlier lesson notes may mention the next lesson as future work; all six are now linked from the main README.

Algorithm names refer to established methods. Implementations include teaching-specific choices, described in each lesson. Sources for structural equations and algorithms are linked in the original OKU.md files. These links are inherited from the lesson packages; this packaging pass does not claim a new source verification.

Türkçe: Bu çalışma öğretmenin silinen tahta örneğinin kopyası değildir. Eğitim için oluşturulan modeller ve algoritma uyarlamalarıdır. Yapay zekâ desteği açıkça belirtilmiştir; testler bağımsız mühendislik onayı değildir.
